# box-chart-maker

Утилита для автоматического построения бокс-чартов в OriginPro 2021. Управляется через консоль.

На входе — папка с сырыми `.txt` от установки для измерения J-V и файл с описанием конфигураций. На выходе — проект Origin с данными и набор `.png`.

---

## Требования

- Windows
- Origin 2021 или новее
- Python 3.12+ — именно Windows Python, не WSL (COM-автоматизация работает только из-под Windows)

Запускать Origin заранее не нужно — утилита поднимет его сама.

---

## Установка

### Для использования

Утилита ставится через [pipx](https://pipx.pypa.io/) — он изолирует
зависимости, но делает команду доступной из любой папки.

    py -m pip install --user pipx
    py -m pipx ensurepath

После `ensurepath` нужно перезапустить PowerShell/cmd.

Дальше из корня проекта:

    pipx install .

Проверка:

    box-chart-maker --help

### Для разработки

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -e ".[dev]"
    pytest

## Формат данных

Утилита на данный момент работает с названиями подложек вида

```
[БУКВА][ЛЮБОЕ КОЛ-ВО ЦИФР]p[ЛЮБОЕ КОЛ-ВО ЦИФР]
```

без квадратных скобок, например `c10p2`.

Токен ищется среди частей имени файла, разделённых `_`, поэтому остальные части могут быть любыми:

```
20260122_SnO2_172_Light_c10p2_Alena.txt
                        ^^^^^
```

Файл будет отклонён, если подходящий токен не найден или найдено больше одного.

## Конфигурации

Для построения бокс-чартов необходимо создать файл с расширением `.yaml` и указать конфиги в виде:

```yaml
configs:
  Control: [c2, c3]
  Config A: [c5, c6, c7]
  Config B: [c10, c11]
  Config C: [c12, c14]
  Config D: [c15, c16]
```

Порядок конфигов в файле задаёт порядок колонок на графике.

Если название конфига состоит из цифр или выглядит как число — следует заключить его в кавычки. Без кавычек YAML прочитает `1.10` как число и превратит в `1.1`.

## Запуск

```powershell
box-chart-maker -d F:\python\box_chart_maker\JV -y F:\python\box_chart_maker\config.yaml -o F:\python\box_chart_maker\OUT -t F:\CustomBoxChart.otpu
```

### Обязательные флаги

| Флаг | Назначение |
|------|------------|
| `-d`, `--data-dir` | путь к папке с исходными данными |
| `-y`, `--yaml` | путь к файлу с конфигами (`.yaml`) |
| `-o`, `--out-dir` | путь к папке для выходных данных (утилита создаёт родительские папки сама) |
| `-t`, `--template` | путь к сохранённому шаблону для OriginPro |

### Необязательные

| Флаг | Назначение | По умолчанию |
|------|------------|--------------|
| `--param` | параметр для выбора лучшего измерения | `pce` |
| `--verbose` | уровень логирования | `INFO` |

## Что получается

Origin-файл с 5 листами в книге. Первый лист — сводная информация по всем измерениям. Затем идут листы, соответствующие разным величинам.

Формат листа — столбец на конфиг, плюс рядом с каждым столбцом с измерениями есть столбец с обозначением подложки и пикселя.

Также утилита сохраняет 4 графика (по 1 на каждую величину) и 1 общий график. Формат `.png`.

---

## Особенности поведения

- При наличии одинаковых измерений по выбранному параметру берётся первое встреченное измерение.
- Измерения `Dark` отсекаются.
- Reverse scan и Forward scan внутри утилиты не различаются.
- Сохранённые `.png` файлы заменяются на новые молча.
